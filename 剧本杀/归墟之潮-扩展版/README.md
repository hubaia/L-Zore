## 🌊 游戏概述

**《归墟之潮》**是一款基于L-Zore世界观的沉浸式剧本杀扩展版游戏。2328年夏至，第一位公开回归现实的先行者在"归潮仪式"上意识崩解，全城神经接入者同时听见了大海的潮信。络尘与旧友们必须在二十四小时内查明：**杀死归客的，究竟是企业的捕网、政府的闸门，还是那片意识海本身？**

本作延续赛博朋克美学与中华命理文化的融合。**游戏机制相对第一部基本全部重写，仅有部分相似，详细规则待后续填充，目前留白。**

### 🎯 核心特色
- **全新机制体系**：不沿用第一部规则，重写设计中（详见后文"游戏机制"留白说明）
- **玩家即是门**：一名玩家角色在游戏后期才会发现自己已被潮主寄生，真相与抉择直击本人
- **节气对称结构**：第一部冬至"一阳生"（上传/出发），第二部夏至"一阴生"（回归/倒灌）
- **赛博×命理**：未来都市、意识海与归墟神话、八字命理的融合叙事

### 🎯 游戏目标
- **主要目标**：查明先行者苏妄在归潮仪式上意识崩解的真相与"凶手"
- **次要目标**：弄清先行者集体回归的原因，以及意识海深处"潮主"的真面目
- **隐藏目标**：找出七人中谁已成为潮主降临的"门缝"，并决定人类与意识海的未来关系

## 🌊 与第一部的衔接（无剧透前提要）

第一部《数据轮回的背叛》结束后半年：

1. **络尘**成为第一个从网络意识大海主动归来的人类，被全社会称为"归人"；ta在海中寻找流光碎片时，曾听见深处有"潮声"回应。
2. **先行者们**开始陆续回归——他们比络尘更早入海，却在此刻才集体归来，原因不明。
3. **林默**（2312年首位人类入海实验者）仍靠药物维持，他在海里遗落过三天的自我。
4. **初代AI晨露**融入意识海守护AI自由意志；企业（泰坦工业）与地下政府都在暗中争夺"双向回归技术"。
5. 第一部中玩家击败的"轮回协议虚拟化人格"，其实只是某个更庞大存在投在协议表层的**一道影子**。

夏至，潮信至。归客成了门。

**本作真相不站在任何阵营一边**：企业的网、政府的刀都不是致命的主因；真正的"凶手链"由一场自愿的牺牲与一个16年前的承诺构成。

## 🌟 文化内涵

- **节气哲学**：冬至阳生（上传/离）、夏至阴生（下载/归），阴阳互根，潮有信而往必复
- **归墟神话**：《列子》所载"归墟"为百川之归、无穷之壑——意识海即数字时代的归墟
- **六冲命理**：传统命理学中冲未必凶，"冲开"亦主破局，呼应角色"以断裂求生"的抉择
- **伏吟局**：商昼八字地支伏吟（重复重现），命理上主呻吟反复，暗喻"他是被海重复出来的人"
- **我与门的思辨**：当一个人成为他者降临的通道，"我是谁、我还剩多少是我"成为终局之问
