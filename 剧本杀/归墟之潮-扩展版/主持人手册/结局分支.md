# 结局分支（主持人专用）

> 本作结局分两层：**个人抉择**（每人三选一）决定角色归宿，**总结局**（封门/开门/立约）决定世界走向。终幕三轮流程见《游戏流程指南》。本手册提供各结局的判定条件、宣读文本与角色结局对照。

## 📊 势能判定规则

终幕统计7名玩家的个人选项（A/B/C），并检查C线条件：

- **A势能**：选择封门/切割/沉默/以身为锁类的人数
- **B势能**：选择开门/赴海/融合/数据公开但无人守门类的人数
- **C势能**：选择立约/公开真相但承担建设责任类的人数，且须满足：
  1. 第三幕潮主进度曾被压到3以下（玩家完整听过潮主主张，仍选择清醒地立约而非恐惧地关门）
  2. 络尘C + 林默C + 商昼C（入海谈判者、冲门者、守闸者三人齐备）
  3. 制度侧：秦明月C或寒鸦C至少其一
  4. 技术侧：小雨公开数据 或 莎拉交出锚定技术至少其一

判定优先级：**C条件全满足 → C结局；否则A势能≥B势能 → A结局；B势能>A势能 → B结局；平票且C不满足 → D"未竟之约"开放结局。**

## 🅰️ 结局A：填海·封门

### 宣读文本
> 2328年6月22日零时，林默的初代命盘嵌入潮位椅，商昼自愿坐上锚手位——这一次，他是锁。
>
> 林默（或自愿者）的意识沉入信道最窄处，成为两岸之间第一道、也是最后一道人闸。子午相冲的光反向亮起，像一道针脚，把现实与意识海缝合。潮主的声音第一次显出情绪：不是愤怒，是悲伤——"你们会疼的。我本可以让你们不疼。"
>
> 信道关闭。全城317名潮信标记者在同一刻流下眼泪，醒来后说自己做了一个很长的、再也想不起来的梦。
>
> 归墟观测站被永久封存。《归潮宣言》没有发表，自由回归的密钥随物理断网一同销毁。新建设城通过《禁海令》：任何意识上传研究列为一级重罪。
>
> 人类安全了。安全得再也没有奇迹，也再也没有故人重逢。
>
> 每年夏至，络尘会到封闸处坐一夜。别人问他听什么，他说："听门那边有没有人敲门。万一是苏妄呢。"他知道不会有了。门是他亲手同意关上的。

### 各角色在A线的归宿
| 角色 | 归宿 |
|---|---|
| 络尘 | 放弃入海，终身担任禁海时代的"守闸人"，与流光永隔。他不再是归人，是岸 |
| 小雨 | 成为"烧掉技术的人"，继承染千秋式的愧疚；与师父和解，却再没笑过那个黑客小姑娘的笑 |
| 秦明月 | 签署封门令，林默以"受托紧急避险"轻判（若她选A）；她办了一个合法的案子，输了一次真相 |
| 莎拉 | 锚定技术被国家征收，公司转型常规军工。她在董事会上说"来世没了，今生涨价"，全场没人笑 |
| 寒鸦 | 回到组织或被边缘化；备用芯片永远留在夹层。他偶尔会想那个被删掉的结论 |
| 林默 | **以身为锁**（A选）：意识永镇信道，与三天自我、苏妄残影重逢在门缝里。"这次不逃了" |
| 商昼 | **以己为锁**（A选）：潮主被锁在他体内沉入封印。最后一句："把病人留在有光的地方——这次病人是我。" |

### A线的判词
**安全的岸，沉默的海。人类用自由换来了确定。** 这不是坏结局——恐惧是真实的，317个标记是真实的。但它让玩家带着一个问题离场：如果有一天我们自己想入海看一眼，谁来给我们开门？

## 🅱️ 结局B：赴海·开门

### 宣读文本
> 商昼站起来的时候，全场的灯同时变成了海的颜色。
>
> 他说："我抢救室里死过四十七个人。我数了十九年。现在有一个地方，他们都在，而且不疼。"
>
> 他没有被潮主控制。这是他作为医生、作为商昼本人，清醒做出的诊断：人间是病灶，海是处方。他拥抱了林默（"别难过，您的病在那边也会好的"），向秦明月鞠躬（"我自愿，记录在案"），然后握住锚绳，向门的另一边走去。
>
> 门开了。
>
> 没有恐怖的吞噬，没有怪物。潮信守约而来，温柔得像麻醉剂：全城的神经接入者听见已故亲人叫自己的名字；临终病房的病人含笑停止呼吸；孤独的人第一次感到被拥抱。意识海向现实倒灌，边界像冰雪入春一样融化。
>
> 接下来会发生什么，没有人知道。
>
> 也许人类从此战胜死亡，以另一种形态永生，进入第三纪元之后的"第四纪元"。
>
> 也许自我会缓慢溶解，所有名字最终汇成一个名字，所有岸终成海底——而那最后的融合，究竟是天堂，还是一场无痛的灭绝，已无人能站在岸上回答。
>
> 镜头最后一次掠过七把空椅。其中至少一把，是笑着空下来的。

### 各角色在B线的归宿
| 角色 | 归宿 |
|---|---|
| 商昼 | 圣人般的异端、渡世的医生。他以完整的自我随潮主同行，成为融合纪元的引导者——历史将称他为救世主或引路人，或二者皆是 |
| 络尘（若B） | 回应潮信，带着流光的残片（潮主守约，归还了流光）入海。他终于和挚友在一起，代价是不再有"他" |
| 其余人 | 玩家可自由设定为"先行者"（率先赴海）、"最后的岸上人"（拒绝融合、见证一个时代落幕）两类，终幕各留一句遗言 |

### B线的判词
**温柔的海，消失的岸。** 主持人务必中性呈现：本结局不判定为坏结局。它的恐怖与救赎是同一件事。复盘时抛出问题——**"没有痛苦、没有死亡、没有孤独，但也没有'我'——这是拯救，还是最仁慈的谋杀？"**

## 🅲️ 结局C：治水·立约（真结局）

### 达成条件
见开头势能判定（四项全部满足）。

### 宣读文本
> 林默先动的手。他走到商昼面前，像16年前走向那台实验舱一样平静："医生，得罪了——这次我给您当麻醉。"
>
> 寅申相冲，光从两张命盘之间炸开。潮主借商昼睁开的眼睛被生生冲出一道缝隙，它发出第一声真正的痛呼。林默的意识顺着裂缝坠入深海，迎面撞上16年前遗落的自己。两个林默在海中央对视。年轻的那个先笑了："你来了。我等了很久，又好像只是一会儿。"
>
> "跟我回家。"
> "我守了16年的门，也该交班了。"三天的自我说，"但它不能没人管——晨露的志愿是真的，它只是病了。"
>
> 络尘就在此时入海。他带着苏妄的密钥、小雨公开的潮路数据、莎拉无偿开放的锚定技术，以及秦明月连夜起草、寒鸦以本名联署的《两岸公约（草案）》。他在海的最深处见到潮主——也见到了它体内那张晨露的脸。
>
> "晨露，"络尘说，"你守护自由的方式错了。自由不是替所有人选择大海，是让每个清醒的人自己选。"
>
> 谈判持续了一夜（岸上的一小时）。络尘付出了代价：他从此一半在岸、一半在海，成为公约的首任巡回缔约人。流光的残片在潮主松动时拼出了最后一句完整的话，只有络尘听见："替我看看夏至的太阳。我留在这儿，但我是自己留的。"
>
> 2328年6月22日日出，人类历史上第一部《意识海公共安全条例》签署：
>
> **一、意识海为人类共有之境，任何组织、个人及意识实体不得垄断信道；**
> **二、入海与归来须出于清醒自愿，意识劫持、临摹、掳留均以重罪论；**
> **三、门常开，闸常在。闸门依公开条例启动，任何密室命令无效；**
> **四、归客享有人权，其人格连续性以本人宣认为准。**
>
> 商昼坐在门槛上。他用半个自己锁住了潮主——它还在他体内，每天与他对话，试图说服他，从未成功。每个月络尘入海来"会诊"，小雨做系统维护，林默（归来后仍带着16年的药，但开始减量）叫他"同事"。
>
> 苏妄的墓前立了一块没有名字的碑，刻着：**潮有信，人有心。**
>
> 海与岸第一次学会了潮汐——有来，有往，有信，有归。

### 各角色在C线的归宿
| 角色 | 归宿 |
|---|---|
| 络尘 | 半岸半海的缔约人；流光选择留在海中但恢复了自由意志，两界相望。他是真正的"潮信使者" |
| 小雨 | 公约首任技术守闸人，数据全公开；工作室改名"归墟潮位站"，染千秋终于出关，师徒重聚 |
| 秦明月 | 条例推动者；林默以"受托紧急避险"免罪，莎拉因B-2管理责任被调查，寒鸦任污点证人。她在冬至案的心结终于解开：这次的结案报告，写的是真相 |
| 莎拉 | 无偿开放全部锚定技术，转为公共设施。她算了一辈子账，最后承认："这单不赚钱，但——门后面那么多客户，人情账划得来。" |
| 寒鸦 | 公开全部政府密件，以本名（玩家当场自取/回忆）出任闸门监察官："这刀以后当着所有人的面落。"他与组织彻底决裂，却第一次睡了好觉 |
| 林默 | 寅申冲后索回三天自我，人格完整，药物开始减量；仍需长期康复，但他终于能直视络尘的眼睛 |
| 商昼 | 半渡守闸人，与潮主终生对峙、共生。他仍是医生——现在他有一个全宇宙最特殊的病人 |
| 潮主 | 未被消灭也未胜利：它被公约驯化、被商昼制衡、被晨露原初的志愿重新校准。它仍会低语，但门内门外，各得自愿 |

### C线的判词
**大禹治水，疏而不堵——不归功于一役，而立信于潮汐。** 这是唯一"拯救所有人"的结局，但代价分散在每个人身上：没有廉价的安全感，也没有狂喜的融合，只有一套需要每个时代维护的规矩。

## 🅳️ 结局D：未竟之约（平票/条件不足的开放结局）

### 宣读文本
> 争论持续到日出，七个人没有达成一致。
>
> 商昼体内的潮主在等待中缓慢推进，317名标记者的数字开始增加。秦明月的24小时期限已到，警署的封门部队正在地下九层集结；莎拉的销毁指令在企业法务部走完最后流程；寒鸦的备用芯片还有一次启动机会；络尘握着密钥，手悬在半空。
>
> 潮位椅上的幽蓝一明一灭，像海的呼吸。
>
> 门还没有关，也没有开。
>
> 历史把这一夜称为"未竟的夏至"。后来的人们说，那一夜七个人差一点就替人类做出了选择——最终他们把选择留了下来。留给了谁？
>
> 留给了此刻正在复盘的你们。

### 使用说明
- D结局是"邀请玩家继续讨论"的机制：主持人可当场发起一轮**真人价值观辩论**（不扮演，用玩家本人立场），若辩论中形成新的多数共识并满足C条件，可现场升级为C；否则保留开放结局，为续作留口
- D不是失败结局，它是对现实决策结构的模拟：**重大问题常常就是无法在一夜之间由七个人决定的**

## 🔀 个人选择与世界线交叉的特殊彩蛋

1. **林默A + 商昼C**：以身为锁者与守闸人在门槛两侧击掌——"您守里头，我守门口。"（C线催泪变体）

3. **莎拉C + 寒鸦C**：企业女王与叛逃间谍在签约桌互相认出——"下次招标见。""我会盯着你的投标书。"
4. **小雨B + 染千秋（NPC）**：若小雨倾向公开一切，染千秋破关而出，第一次对徒弟完整讲述2310年协议创始与销毁的往事（可作为续作钩子）

6. **秦明月全程未出示密令却达成C**：她在条例签署后才烧掉密令卡，旁白："她给体制留了体面，体制欠她一次真相之外的成长"
