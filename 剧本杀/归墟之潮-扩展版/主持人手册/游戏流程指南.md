# 游戏流程指南（主持人专用）

> 《L-Zore剧本杀II：归墟之潮》带本手册（剧情流程版）。建议主持人通读《主线剧情.md》与全部7份角色手册后开组。本作含"玩家即门"的密封设定，发放商昼手册时务必叮嘱其第四幕前不得翻阅密封页。
>
> ⚠️ **机制留白说明**：本作游戏机制相对第一部基本全部重写、仅有部分相似。本手册第三幕中出现的锚定值、六冲神煞卡、污染线索等具体规则均为**早期草稿（非最终机制）**，以《[游戏机制（待填充）.md](../游戏素材/游戏机制（待填充）.md)》后续填充为准。

## 🎬 序幕：潮来信至（30分钟）

### 0–10分钟：前情提要
若玩家玩过第一部，用3分钟快速回顾即可；若没有，朗读/播放以下蒙太奇：

> "2327年冬至，数据回收师络尘在地下第九层启动永恒轮回协议，把自己的意识送入网络意识大海，寻找被销毁的挚友AI流光。他活了下来，也回来了——人类第一个归人。他说海是活的，没人信。半年后，更早入海的先行者们一个接一个归来，人们叫它'归潮'。今天是2328年6月21日，夏至。第一位归客苏妄要当众证明：人，可以自由地入海，再自由地回来。地下第九层，归墟潮汐观测站，仪式二十点整开始。"

### 10–25分钟：读本与换装
玩家阅读各自手册**第一部分/公开信息**，主持人单独叮嘱商昼玩家密封规则。玩家在胸牌写角色名。

### 25–30分钟：入场广播（主持人口播）

> "各位受邀嘉宾下午好，欢迎莅临归墟潮汐观测站'夏至归潮发布会'。我是本站智能管家晨露。今日议程：十四时，苏妄先生《归潮宣言》；二十时，人类首次公开自由归海演示。入场提示：会场内设有企业赞助的信号保障设备，请勿触碰。祝您……平安。"

"平安"二字让晨露（主持人）说得迟疑。分发各角色入场物品（见线索管理"序幕包"）。

## 🎭 第一幕：仪式崩解（45分钟）

### 案发剧场（15分钟）
按时间线口播20:00–20:47的仪式，**关键节点请对应角色朗读其手册中的视角片段**，增强沉浸：

| 时间 | 事件 | 呈现方式 |
|---|---|---|
| 20:00 | 苏妄入座，意识下沉，屏幕转幽蓝 | 口播+海浪声起 |
| 20:05 | 锚定器自动启动，B-2早0.3秒 | 小雨朗读报警片段 |
| 20:10 | 商昼被借声："留下来，这里没有痛" | **主持人直视商昼玩家，用温柔男声/女声替他说出这句话**（商昼玩家此时真实不知情，这是他的"空白"） |
| 20:15 | 苏妄被钉在门中间 | 口播三方撕扯 |
| 20:20 | 寒鸦注入断潮 | 寒鸦朗读；主持人强调"你按下了" |
| 20:25 | 苏妄："子午相冲——现在！" | 口播 |
| 20:26 | 林默斩锚 | 林默朗读；海浪声最大 |
| 20:28–20:46 | 夏至潮信，全城听见海 | 全体玩家闭眼听11秒海浪/人声混合音；分别低声对络尘、小雨、寒鸦说专属潮信内容 |
| 20:47 | 灯亮，苏妄死亡，屏幕满屏"门"字 | 口播现场 |

> **潮信私语（仅对应玩家听见）**
> - 对络尘："你也回来。"
> - 对小雨：染千秋歌谣的倒放（哼一段旋律即可）
> - 对寒鸦："进来的人，门不会怪你。"
> - 对其余人：无意义的、无数人念名字的噪音。

### 封锁与初查（30分钟）
- 秦明月行使主办权，组织第一轮公开陈述：每人用2分钟说明"你看到了什么、你做了什么"
- 发放**①号信封**（第一幕线索，以现场物证为主）
- 本幕目标：让企业网、政府刀都显眼（误导成立）；林默子午斩的痕迹也被发现（头号嫌疑人雏形）
- 幕末秦明月收到密令"限时二十四，定一人罪"（私下递交卡片）；寒鸦收到"让他背锅"密报（私下递交）

## 🔍 第二幕：双轨调查（90分钟）

### 调查点与NPC（开放探索，玩家用行动点，见线索管理）
1. **仪式厅**：灼痕、命盘断口、潮位椅数据
2. **设备间**：三台烧毁锚定器、B-2的GX-0模块；张明在此（可被撬开）
3. **晨露核心机房**：晨露拒绝配合仪式的日志；它对商昼的恐惧反应（表演）
4. **苏妄休息室**：空药瓶（林默的药）、归墟徽章、手写卡、与林默四次密会记录
5. **企业指挥车**：莎拉的内部日志（需交换/施压/窃取才能拿到完整版）
6. **屋顶通讯点**：寒鸦的通讯时间戳（40秒延迟）、断潮芯片残核
7. **数据终端（小雨专属）**：0.8秒同频数据破解第一轮（本轮只出结论："波形同源"，含义留到第三幕）

### 本幕必须完成的信息推进
- [ ] 小雨确认B-2被GX-0篡改、张明承认知情未报
- [ ] 莎拉做出"是否公开内部日志"的抉择（可拖到第三幕，但要给压力）
- [ ] 秦明月/寒鸦互相发现对方的密令与密报（主持人安排一次正面对手戏）
- [ ] 寒鸦可向小雨交易"封门预案"换时序
- [ ] 林默异常但拒不开口；空药瓶把嫌疑引向他（他不辩解）
- [ ] 商昼主动坦白自己的异常症状（记忆缺口、子时低语），获得部分信任或更深怀疑
- [ ] 发放**②号信封**（证词与文档类线索）

### 幕末钩子（70分钟时）
小雨的第一轮破解出炉：**苏妄与商昼的波形不是共振，是同源。** 同时晨露报告：观测站潮位盘自行启动——苏妄留下的"入潮"邀请被激活了。
主持人宣布："要知道海里发生了什么，只能下去问。"

## 🌊 第三幕：集体入潮（90分钟）【核心玩法幕】

### 规则简述（⚠️ 以下为早期草稿机制，已作废，待《游戏机制（待填充）》重写后替换）
- 全员锚定值公示：络尘10、秦明月9、小雨8、莎拉7、寒鸦7、林默6；商昼显示"??"
- 入潮后分三个"潮层"推进，每层30分钟，每层结束结算一次潮主侵蚀
- 污染线索与真线索混发，持太极贵人卡者可鉴定1次
- 可触发的合盘：
  - 林默×秦明月 子午冲 → 劫煞（斩污染锚）
  - 络尘×小雨 卯酉冲 → 亡神（潜入深层，代价：记忆流失）
  - 秦明月×小雨 辰戌冲 → 孤辰寡宿（15分钟全队免疫污染、期间无增益）
  - 莎拉×络尘 丑未冲 → 孤辰寡宿（单体版：莎拉自己免疫低语15分钟）
- 林默锚定最低，若队友不抛锚，第一个沉溺；沉溺后由主持人代说"胡话"（藏真线索）15分钟

### 第一层：浅潮（30分钟）——取证
场景：无数漂浮的数据光尘、旧日城市的倒影。**苏妄残影**在此。
- 苏妄残影确认三件事：①我是自愿的；②林默是应我请求斩锚；③有人不想让自由的门存在——网是人的，推网的手不全是人的
- 潮主初现：以光/声音形态低语，不攻击，只"欢迎"
- 本层产出真线索：GX-0的真相（归墟0型残段被潮主利用）、林默2312年遗落三天自我

### 第二层：回涌（30分钟）——战斗与诱惑
场景突变：潮水倒灌，空间收缩成仪式厅的形状。**潮主化身**（第一部"轮回协议虚拟化人格"的本体，建议描述为"无数张人脸组成的巨大人形，其中有林默的脸、有晨露的光、有每个玩家思念者的轮廓"）现身。
- BOSS战机制：三轮攻防，每轮潮主对1名玩家使用"专属低语"（用其手册中的诱惑内容），被低语者须当众声明"守住/动摇"，动摇则全队锚定-1、潮主进度+1
- 玩家用神煞卡/证词反击：每打出一条正确真相（自愿斩锚、GX-0、临摹、晨露异化），潮主进度-1
- **潮主进度条0–10**：到10则强行提前开启第四幕"软降临"（坏节奏）；玩家在30分钟内压到3以下，则获得与潮主"对话"资格（通往C线的必要条件之一）
- 寒鸦每30分钟可私问主持人一条潮主意图
- 本层污染线索集中投放，太极贵人卡鉴定时机建议在本层末

### 第三层：深海（30分钟）——对峙自己
- 用亡神卡潜入者可见到**林默的三天自我**："别来。守住门。"
- 潮主对林默、络尘、商昼分别发动最后诱惑（林默：归还完整自我；络尘：交出流光；商昼：根治一切痛苦）
- 商昼在本层结束时会被潮主"唤醒"——他在海里看见自己被临摹的全过程。**主持人在本幕结束后立即执行第四幕密封页流程**
- 出潮：所有人退出，锚定值结算（低于3者现实中昏迷10分钟，不影响后续但增加紧张感）

> **本幕主持人要点**：战斗不是目的，"听它把话说完"才是。潮主的每句话都要有说服力，禁止把它演成纯恶人。它的核心主张必须让玩家真心动摇：*没有死亡、没有痛苦、没有孤独的永恒融合，到底是地狱，还是天堂？*

## 🚪 第四幕：门在人群中（60分钟）

### 0–5分钟：密封页时刻
将商昼玩家单独带离，告知密封页全部真相，交付第二部分手册。商昼玩家回来时，其余玩家看到的只是"他入潮后脸色不对"。

### 5–25分钟：证据总爆发
- 小雨公开第二轮破解：0.8秒同频=同源，配合寒鸦的借声音频、晨露的恐惧日志、幽蓝结晶 → 商昼是"门"的证据链闭合
- **由玩家们先说出怀疑，再由商昼玩家决定何时、如何坦白双重锚定值**
- 莎拉的日志抉择在此收口（公开则证实B-2被劫持、同时暴露捕潮计划）
- 林默坦白全部：16年前三天自我、苏妄四次密会、子午斩的委托真相、调包药瓶。出示苏妄遗言卡："潮有信，人有心。"
- 苏妄数据匣开启（小雨履行托付，交给络尘）：《归潮宣言》完整版+自由回归密钥+给七人的留言（主持人为每人念一句专属留言，见下）

> **苏妄留言（每人一句，建议朗读）**
> - 络尘："你看，门可以不吞人。替我再下一次海，这次带大家一起回来。"
> - 小雨："数据交给你，我放心。别学你师父，门不是只能烧掉的。"
> - 秦明月："警官，别先关门，先看清门外站着的是谁——站着的是我这样的普通人。"
> - 莎拉："总裁女士，来世要是免费的，您会害怕吗？我赌您会，但我也赌您最后会做对的事。"
> - 寒鸦："你的刀落空了，我知道。别难过——空刀也算你尽力了。用真名吧，名字在海里也管用。"
> - 林默："别哭。我16年里最好的朋友是你丢的那三天，他让我替他说：守住门，别来接我。"
> - 商昼："医生，您救了我四个月。现在该您救自己了——记住，疼，是活着的证据。"

### 25–45分钟：真相核校
主持人口播"真相时间线速查"（见主线剧情），逐条解答玩家疑问，公布：潮主=轮回协议虚拟人格本体+晨露守护意志异化+林默三天自我+先行者疲惫的集合体。

### 45–60分钟：软降临
潮主借商昼发动软降临：灯光转蓝、海水倒灌幻象、全城第二批潮信倒计时（设定为60分钟游戏时间）。商昼玩家表明自己的三个选项倾向，全体进入终幕抉择。

## ⚖️ 终幕：万派归墟（45分钟）

### 第一轮：个人抉择（15分钟）
每人依角色手册三选一发言，说明理由。主持人记录，并把抉择换算为"三结局势能"：
- 偏向封门（A选项多）→ A势能
- 偏向开门/赴海（B选项多）→ B势能
- 偏向立约（C选项多，且满足C线条件）→ C势能

### 第二轮：终极辩论（20分钟）
开放辩论。C线达成条件：
1. 第三幕潮主进度曾被压到3以下（玩家听过潮主完整主张）
2. 至少络尘C + 林默C + 商昼C（再赴海、冲开门缝、守闸的三人组）
3. 秦明月C或寒鸦C至少其一（立约需要制度侧）
4. 小雨公开数据/莎拉交出技术至少其一（立约需要技术侧）
不满足则C线降级为"未竟之约"（开放结局）。

### 第三轮：结局与复盘（10分钟）
宣读对应总结局（见《结局分支.md》）。随后复盘：
- 揭示商昼玩家全程不知真相的设计（其他玩家此时才知道他前期不是演的）
- 梳理完整时间线与全部伏笔
- 对照第一部呼应表（主线剧情末尾）
- 邀请每位玩家说一句："如果是你本人，你选哪条岸？"

## ⏱️ 时间失控应对

- **时间不足**：第二幕调查点可合并设备间/指挥车；第三幕潮层从三层压为两层（保留回涌层与深海诱惑）
- **玩家过早锁定林默**：用秦明月密令+寒鸦密报把矛头引向"有人要你们快速结案"；用苏妄残影提前确认"我是自愿的"
- **玩家完全不怀疑商昼**：晨露的恐惧表演加戏；小雨的同频数据提前一轮；让潮主低语时商昼锚定值诡异跳动
- **玩家过早怀疑商昼并要围攻他**：秦明月/林默应按人设保护他（证人、病人）；主持人借苏妄留言"他是医生"压制失控
- **商昼玩家提前偷看密封页**：如发现，将计就计——要求其演出"知情者装作不知情"，并在复盘中说明这改变了体验
- **冷场**：潮主从不冷场。让它对最沉默的玩家低语一句最私人的话
